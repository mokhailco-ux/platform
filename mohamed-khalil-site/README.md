# موقع الأستاذ محمد خليل - فيزياء ورياضيات

موقع تعريفي احترافي مبني بـ **Next.js 14 + React + TypeScript + Tailwind CSS + Framer Motion**.

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

## البناء للنشر

```bash
npm run build
npm run start
```

يمكنك نشر المشروع مباشرة على **Vercel** (الطريقة الموصى بها لمشاريع Next.js) بربط المستودع من GitHub.

## هيكل المشروع

```
app/               صفحات الموقع (App Router)
  ├─ page.tsx       الصفحة الرئيسية
  ├─ layout.tsx      القالب العام + SEO
  ├─ admin/         لوحة تحكم بسيطة لإضافة محتوى تسويقي (غير متصلة بقاعدة البيانات)
  ├─ student/        منصة الطلاب المحمية (دورات + فيديوهات)
  ├─ signup, login/   تسجيل الحساب والدخول
  ├─ checkout/        صفحة الدفع (Moyasar)
  └─ api/contact/    نقطة استقبال نموذج التواصل
components/         كل أقسام الموقع (Hero, Courses, FAQ ...)
lib/data.ts         كل البيانات القابلة للتعديل (الدورات، الفيديوهات، الآراء، الأسئلة الشائعة)
```

## إضافة محتوى جديد بسرعة

- **دورة جديدة / فيديو جديد / رأي طالب جديد على الصفحة الرئيسية (التسويقية)**: افتح `lib/data.ts` وأضف عنصرًا جديدًا لنفس المصفوفة بنفس الشكل، أو استخدم لوحة `/admin` (كلمة المرور الافتراضية: `physics2026` - غيّرها من داخل `app/admin/page.tsx` قبل النشر).

> ⚠️ **مهم**: بيانات `lib/data.ts` تُستخدم فقط لعرض الدورات على الصفحة الرئيسية التسويقية (Marketing). أما **الدورات الفعلية التي يشترك فيها الطلاب** (بحسابات وفيديوهات محمية) فهي مخزّنة في قاعدة بيانات Supabase، وتُدار من جدول `courses` و`course_videos` مباشرة (راجع القسم التالي). حاليًا هما نظامان منفصلان - يمكن ربطهما لاحقًا إذا احتجت.

## إعداد منصة الطلاب (الحسابات + الفيديوهات المحمية + الدفع)

هذا الموقع يتضمن نظام منصة تعليمية كامل: تسجيل حساب، فترة تجربة مجانية، دفع إلكتروني عبر مويسر (Moyasar)، وفيديوهات محمية لا يشاهدها إلا الطالب المسجّل. لتفعيله اتبع الخطوات التالية بالترتيب:

### 1) إنشاء مشروع Supabase (قاعدة البيانات + الحسابات)
- أنشئ حسابًا مجانيًا على https://supabase.com وأنشئ مشروعًا جديدًا.
- من **Project Settings → API** انسخ: `Project URL`، `anon public key`، و`service_role key` (سرّي جدًا - لا تشاركه لأحد).
- من **SQL Editor** داخل Supabase، افتح استعلامًا جديدًا، الصق محتوى ملف `supabase/schema.sql` بالكامل من هذا المشروع، ثم اضغط **Run**. هذا ينشئ كل الجداول والحماية اللازمة تلقائيًا.
- (اختياري) من **Authentication → Providers** تأكد أن تسجيل الدخول بالبريد وكلمة المرور مفعّل (مفعّل افتراضيًا).

### 2) إنشاء حساب مويسر (بوابة الدفع)
- أنشئ حسابًا على https://moyasar.com وفعّل حسابك التجاري (يحتاج مستندات تجارية للتفعيل الكامل، لكن يمكنك التجربة فورًا بمفاتيح الاختبار `pk_test_`/`sk_test_`).
- من لوحة التحكم انسخ **Publishable Key** و**Secret Key**.
- من **Settings → Webhooks** أضف رابط: `https://your-domain.com/api/webhooks/moyasar` مع Shared Secret من اختيارك (احفظه، ستحتاجه بالخطوة التالية).

### 3) إعداد المتغيرات البيئية
- انسخ ملف `.env.example` باسم `.env.local` واملأ كل القيم (روابط ومفاتيح Supabase وMoyasar).
- عند النشر على Vercel، أضف نفس المتغيرات من **Project Settings → Environment Variables**.

### 4) إضافة دورات وفيديوهات فعلية للمنصة
حاليًا لا توجد واجهة رسومية لإضافتها (لتبسيط المرحلة الأولى) - أضفها مباشرة من Supabase:
- **Table Editor → courses**: أضف صفًا جديدًا (العنوان، المادة، المرحلة، السعر، عدد أيام التجربة المجانية).
- **Table Editor → course_videos**: أضف فيديو واربطه بـ `course_id` الخاص بالدورة، وضع `youtube_id` (يُفضّل أن يكون الفيديو "غير مدرج/Unlisted" على يوتيوب - وليس عامًا - كطبقة حماية إضافية).

### 5) تجربة النظام كاملًا
```
npm run dev
```
- افتح `/signup` وأنشئ حساب طالب تجريبي.
- افتح `/student` وستشاهد الدورة مع زر "ابدأ الفترة المجانية".
- بعد بدء التجربة، افتح الدورة وشاهد الفيديو (تأكد أنك أضفته بالخطوة 4).
- جرّب الدفع بزر "ادفع الآن" باستخدام بطاقة الاختبار الخاصة بمويسر (موجودة في وثائقهم) للتأكد أن الاشتراك يتفعّل تلقائيًا بعد الدفع.

### كيف تعمل الحماية فعليًا؟
- لا يمكن لأي أحد الوصول لرابط فيديو دورة معيّنة إلا إذا كان مسجّل دخول **و**لديه اشتراك فعّال (تجربة سارية أو دفع مكتمل) - يتم التحقق من هذا في السيرفر (`app/student/courses/[id]/page.tsx`) قبل جلب أي رابط فيديو، وليس فقط بإخفاء الزر بالواجهة.
- جدول `course_videos` في قاعدة البيانات مُقفل بالكامل (RLS) بحيث لا يقدر أي متصفح يقرأه مباشرة مهما كانت الحيلة - فقط السيرفر نفسه (بمفتاح Service Role) يقدر يقرأه، وهذا بعد التحقق من الصلاحية.
- **حدود هذه الحماية**: الفيديو نفسه لا يزال مستضافًا على يوتيوب، فطالب مسجّل ومشترك فعليًا يقدر تقنيًا يسجّل شاشته أو يجد رابط الفيديو المباشر بأدوات المطوّر بالمتصفح. لمنع هذا تمامًا (حماية DRM حقيقية ومنع التحميل) تحتاج خدمة استضافة فيديو متخصصة مثل Bunny Stream أو Mux بدل يوتيوب - يمكنني مساعدتك بذلك لاحقًا إذا احتجته.

## أشياء يفضّل تعديلها قبل النشر الفعلي

1. أرقام التواصل وروابط التواصل الاجتماعي في `lib/data.ts` (كائن `social`).
2. رابط الموقع (`metadataBase` و`siteUrl`) في `app/layout.tsx` و`app/sitemap.ts` و`app/robots.ts`.
3. ربط نموذج التواصل في `app/api/contact/route.ts` بخدمة بريد فعلية (مثل Resend) بدل التسجيل في الـ console فقط.
4. كلمة مرور لوحة التحكم، ويُفضّل استبدالها بنظام تسجيل دخول حقيقي إذا كثر المحتوى.
5. استبدال معرّفات فيديوهات اليوتيوب التجريبية في `lib/data.ts` بفيديوهاتك الفعلية.

## الخصائص

- تصميم متجاوب بالكامل (جوال / تابلت / ديسكتوب).
- دعم كامل للغة العربية واتجاه RTL.
- وضع ليلي وفاتح.
- حركات وانتقالات ناعمة بـ Framer Motion (مع احترام `prefers-reduced-motion`).
- عدادات متحركة للطلاب والدورات وساعات الشرح.
- تحسين SEO: Metadata، Open Graph، Sitemap، robots.txt، بيانات Schema.org.
- لوحة تحكم مبسطة لإضافة دورات وفيديوهات مستقبلًا.
